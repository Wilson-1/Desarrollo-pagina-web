# Portafolio de Wilson Criollo 🚀

Sitio web profesional de portafolio personal para Wilson Criollo, desarrollador web con más de 3 años de experiencia en soluciones digitales innovadoras.

## 📋 Descripción del Proyecto

Portafolio web moderno y responsive que muestra servicios, proyectos destacados, información personal y opciones de contacto. Diseñado con enfoque mobile-first y optimizado para todos los dispositivos.

## 🎯 Características Principales

- **Diseño Responsive**: Adaptado para celulares, tablets y escritorio
- **Navegación Sticky**: Barra de navegación fija en la parte superior
- **Secciones Organizadas**:
  - Hero section con llamada a la acción
  - Sobre mí (biografía, habilidades, experiencia)
  - Servicios (6 servicios con descripciones)
  - Portafolio (6 proyectos destacados)
  - Contacto (formulario e información de contacto)
  - Footer con redes sociales

- **Optimización SEO**: Meta tags, estructura semántica HTML5
- **Seguridad**: Enlaces externos con `rel="noopener noreferrer"`
- **Estilo Moderno**: Gradientes, animaciones suaves, sombras y efectos hover

## 🎨 Diseño y Estilo

### Paleta de Colores
- **Primario**: #667eea (Morado azulado)
- **Secundario**: #764ba2 (Morado oscuro)
- **Nav**: #2c3e50 - #34495e (Gris oscuro)
- **Fondo**: Gradiente 135deg de #667eea a #764ba2

### Tipografía
- Fuente: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif
- H1: 56px (32px en móvil)
- H2: 28px (18px en móvil)
- H3: 42px (24px en móvil)

### Breakpoints Responsive
- **Escritorio**: 769px+
- **Tablets**: 481px - 768px
- **Celulares**: 320px - 480px

## 🔧 Tecnologías Utilizadas

- **HTML5**: Estructura semántica
- **CSS3**: Flexbox, Grid, Gradientes, Animaciones
- **JavaScript**: Navegación interactiva
- **Responsive Design**: Media queries y mobile-first

## 📱 Optimizaciones Mobile

✅ Navegación vertical en celulares
✅ Tarjetas de servicios apiladas (1 por fila)
✅ Proyectos en grid de 1 columna
✅ Formulario simplificado
✅ Botones optimizados para tocar
✅ Sin scroll horizontal en cualquier orientación
